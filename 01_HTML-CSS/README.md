# HTML & CSS Learning Resources

This directory contains the HTML and CSS materials for the Web Development course. It is organized into structured lessons, practical exercises, and example projects to support learning and experimentation.

## Structure

- `HTML-CSS-Quick-Revision.md` — summary notes for quick review of HTML and CSS concepts.
- `Job_Application/` — sample job application landing page.
- `Lesson1/` through `Lesson10/` — lesson content with HTML examples and syntax reference files.
- `Lesson6/` — includes a separate CSS stylesheet demonstration.
- `Lesson7/` and `Lesson9/` — contain dedicated question folders for practice problems.
- `Pokemon_Card_Game/` — interactive card game example with HTML and CSS.
- `Shapes_Game/` — geometric shapes game example with HTML and CSS.
- `Tribute_Website/` — tribute page project with a standalone stylesheet and image assets.

## Usage

1. Open any `.html` file in a web browser to preview the page.
2. Modify the associated `.css` files to update styling and layout.
3. Use the lesson `Syntax.html` and `Ques.md` files for reference and practice.

## Notes

- The folder is designed for hands-on learning and incremental improvement.
- Each lesson is self-contained and can be reviewed independently.
- Project folders demonstrate real-world application of HTML and CSS fundamentals.
