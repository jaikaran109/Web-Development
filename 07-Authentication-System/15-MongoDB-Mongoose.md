# MongoDB & Mongoose

## Overview

**MongoDB** is a NoSQL database that stores data as JSON-like documents rather than rows and tables. **Mongoose** is an Object Data Modeling (ODM) library for Node.js that provides a schema-based abstraction over MongoDB, making it easier to define data structures, validate input, and interact with the database.

| | MongoDB | Mongoose |
|---|---|---|
| Type | Database | Library / ODM |
| Role | Stores data | Defines schema and provides an API to interact with the database |
| Data structure | Schema-less by default | Enforces a defined schema |

## Installation

```bash
npm install mongoose
```

## Connecting to MongoDB

```javascript
const mongoose = require('mongoose');

mongoose.connect('mongodb://localhost:27017/authApp')
  .then(() => console.log('Database connected'))
  .catch((err) => console.error('Connection error:', err));
```

For production, the connection string is typically stored in an environment variable rather than hardcoded:

```javascript
mongoose.connect(process.env.MONGODB_URI);
```

## Defining a Schema and Model

A schema defines the shape of documents within a collection.

```javascript
const userSchema = new mongoose.Schema({
  username: { type: String, required: true },
  email: { type: String, required: true, unique: true },
  password: { type: String, required: true },
  createdAt: { type: Date, default: Date.now }
});

const User = mongoose.model('User', userSchema);
```

The model (`User`) is the interface used to create, read, update, and delete documents in the corresponding collection.

## CRUD Operations

### Create

```javascript
const newUser = new User({
  username,
  email,
  password: hashedPassword
});

await newUser.save();
```

### Read

```javascript
const user = await User.findOne({ email });
const userById = await User.findById(userId);
```

### Update

```javascript
await User.findByIdAndUpdate(userId, { username: 'newUsername' });
```

### Delete

```javascript
await User.findByIdAndDelete(userId);
```

## Applied Example: Registration and Login

```javascript
// Registration
app.post('/register', async (req, res) => {
  const { username, email, password } = req.body;
  const hashedPassword = await bcrypt.hash(password, 10);

  const newUser = new User({ username, email, password: hashedPassword });
  await newUser.save();

  res.status(201).send('User registered successfully');
});

// Login
app.post('/login', async (req, res) => {
  const { email, password } = req.body;
  const user = await User.findOne({ email });

  if (!user) return res.status(404).send('User not found');

  const isMatch = await bcrypt.compare(password, user.password);
  if (!isMatch) return res.status(401).send('Invalid credentials');

  res.status(200).send('Login successful');
});
```

## Notes

- The `_id` field generated by MongoDB for each document is often the value embedded in a JWT payload to identify the user on subsequent requests.
- Schema validation (`required`, `unique`, `type`) provides a first line of defense against malformed data before it reaches the database.
- All database operations in Mongoose return promises and should be used with `async/await` or `.then()/.catch()`.
