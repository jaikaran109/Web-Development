# Git & GitHub

This folder has my notes from learning Git and GitHub as part of my web dev practice.

## What's inside

- **notes.md** – detailed notes on concepts and commands I learned
- **commands-cheatsheet.md** – quick reference for commands I keep forgetting

## Why I'm learning this

Every web dev project needs version control. Git lets me save my progress as I build things, and GitHub lets me back that work up online and eventually collaborate with others. Instead of keeping ten copies of a project named "final", "final2", "final_actually", Git tracks every change properly.

## What I've covered so far

- Setting up Git and connecting it to my GitHub account
- Basic workflow: `add`, `commit`, `push`, `pull`
- Making and switching branches
- Cloning existing repos
- Understanding the difference between saving changes locally (commit) and actually updating GitHub (push)

## Still to explore

- Merge conflicts (haven't hit a real one yet)
- Pull requests properly, beyond just reading about them
- GitHub Actions / CI-CD basics

This is a work in progress and I'll keep updating these notes as I learn more.
